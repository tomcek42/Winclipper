# S01: Assess plaintext persistence risk

**Milestone:** M002
**Slice:** S01

**Goal:** Identify why plaintext stored clip data is unsafe and document the required protection model for future persistence work.
**Demo:** The current clip persistence pattern is mapped to the local-attack risk and a clear decision is made for secure replacement storage.

## Must-Haves

- Current persistence format and exposure path are documented.
- Risk is tied to user-context access and local file manipulation.
- The secure replacement requirement is explicit and justified.

## Proof Level

- This slice proves: Threat analysis and local-attack path review

## Integration Closure

This slice defines the security contract for the persistence changes in downstream slices.

- No runtime change; captures the threat model and required storage protection.
