# S03: Define and enforce trust boundaries for local appdata

**Milestone:** M001
**Slice:** S03

**Goal:** Ensure the project treats %LOCALAPPDATA%\Winclipper\Winclipper\ as an untrusted boundary and not as a safe source of persisted state.
**Demo:** The local Winclipper cache is explicitly treated as untrusted data at startup, and the code and docs state that assumption consistently.

## Must-Haves

- The trust boundary is clearly documented in design notes and code comments.
- Startup and parser assumptions no longer treat local cache as trusted.
- Remaining risk is captured for runtime and operational handling.

## Proof Level

- This slice proves: Design review plus code path review against trust boundary assumptions

## Integration Closure

This slice stabilizes the security assumptions for later persistence and release work.
